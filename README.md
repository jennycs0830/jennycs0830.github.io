# Yi-Jyun Sun — Research Portfolio

Astro static site styled with Tailwind. Content lives in `src/data/site.js`; edit that file to update research, publications, experience, and links. The site builds into `dist/` and can be deployed to GitHub Pages.

## Local preview

Install dependencies with `npm install`, then run `npm run dev`.

## GitHub Pages

Set the repository's Pages source to GitHub Actions and add an Astro build workflow, or run `npm run build` and publish `dist/`. Update `site` in `astro.config.mjs` if using a custom domain or a repository subpath.
